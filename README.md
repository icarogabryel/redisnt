# Redisn't

A minimal Redis-inspired in-memory key-value store written in Rust.

Redisn't is an educational project focused on learning Rust through the
implementation of a TCP server, a simple communication protocol, and an
interactive CLI client.

## Features

- In-memory key-value storage.
- String values.
- Basic commands: `PING`, `SET`, `GET`, `DEL`, `EXISTS`, `FLUSHDB`.
- TCP server with multiple client connections.
- Simplified RESP-inspired protocol.
- Interactive CLI client.

## Project Goals

Learn Rust concepts through practical implementation:

- Ownership and borrowing.
- Data structures and enums.
- TCP networking and I/O.
- Concurrency and synchronization.
- Parsing and serialization.
- Unit and integration testing.
